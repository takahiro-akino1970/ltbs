# 本番構成の説明

本番サーバー構成図は[本番サーバーへの配置](./production.md#本番サーバーの構成)に掲載しています。

## イメージと役割

- `app-order` と `app-admin` は、同じ PHP-FPM アプリ用イメージを使い、環境設定を分けます。
- `web` は、静的ファイルを配信して PHP リクエストを各 PHP-FPM コンテナへ転送する Nginx 用イメージです。
- ホスト側の Nginx は TLS を終端し、Docker 内の `web` に転送します。したがって Nginx はホスト側と Docker 内に1つずつ動作します。
- MariaDB は本番サーバー内で稼働し、この Docker Compose の外にあります。Compose 内のアプリから到達できるよう DB 接続先を設定します。
- `web` のポートはホストの `127.0.0.1:8080` のみに公開し、PHP-FPM のポートはホストに公開しません。MariaDB への接続はアプリからに限定し、インターネットへ公開しないでください。

GitHub Actions のイメージ公開手順は[本番配置](./production.md)を参照してください。
